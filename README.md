# Lounge Movement - CS:GO Community Server

**Lounge Movement**, um site dedicado a um servidor de **Movement** da comunidade CS:GO.

Este site foi criado com o objetivo de divulgar, organizar e fortalecer a comunidade em torno do servidor, além de oferecer informações, estatísticas e atualizações para os jogadores.

---

## 📁 Estrutura do Projeto

- `index.html` — Página inicial do site
- `style/style.css` — Estilo e layout do site
- `scripts/` — Scripts JavaScript (se houver)
- `assets/` — Imagens, logos, ícones, etc.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- [particles.js](https://github.com/VincentGarreau/particles.js)
